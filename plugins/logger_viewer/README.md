# LoggerViewer Plugin - 日志查看器插件

DearTs 框架的日志文件查看、筛选、搜索和分析工具。

## 功能特性

### ✅ 核心功能

- **日志文件读取** - 自动扫描并加载 `build/bin/logs/` 目录下的日志文件
- **DearTs 日志格式解析** - 解析 `[时间戳] [级别] [文件:行号] 消息` 格式
- **多文件支持** - 快速切换不同日志文件

### 🔍 筛选和搜索

- **级别筛选** - 按 TRACE/DEBUG/INFO/WARN/ERROR/FATAL 筛选
- **关键词搜索** - 实时搜索日志内容
- **正则表达式** - 支持复杂模式匹配
- **大小写敏感** - 可选的大小写敏感搜索

### 🎨 可视化

- **彩色标记** - 不同级别使用不同颜色（ERROR红色、WARN橙色、INFO蓝色等）
- **表格视图** - 清晰的列布局（时间、级别、位置、行号、消息）
- **虚拟滚动** - 使用 ImGuiListClipper 优化大文件性能

### 📊 统计分析

- **日志统计** - 显示各级别日志数量
- **去重功能** - 识别并合并重复日志，显示重复次数
- **可见计数** - 显示筛选后的可见条目数

### 🛠️ 操作功能

- **实时刷新** - 重新加载日志文件
- **清空日志** - 清除当前显示的日志
- **自动滚动** - 新日志自动滚动到底部
- **行号显示** - 可选的行号显示

## 技术实现

### 架构

```
LoggerViewerPlugin
├── logger_viewer_plugin.hpp/cpp    # 插件主类
│   └── 实现 IPlugin 接口
│       ├── get_info() - 返回插件信息
│       ├── on_load() - 注册视图
│       └── on_unload() - 清理资源
│
└── views/
    └── logger_viewer_view.hpp/cpp   # 日志查看器视图
        ├── LoggerViewerView (继承 View)
        ├── LogEntry - 日志条目结构
        ├── LogStatistics - 统计信息
        └── 日志解析和筛选逻辑
```

### 日志解析

使用正则表达式解析 DearTs 日志格式：

```cpp
// 格式: [2025-12-29 12:34:56.789] [LEVEL] [file.cpp:123] message
std::regex log_pattern(
    R"(\[(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d{3})\]\s+\[(\w+)\]\s+\[([^:]+):(\d+)\]\s+(.*))"
);
```

### 性能优化

- **ImGuiListClipper** - 虚拟滚动，只渲染可见行
- **预编译正则** - 缓存编译后的正则表达式
- **延迟筛选** - 按需应用筛选条件
- **索引映射** - 使用索引向量避免数据复制

## 使用方法

### 基本使用

1. 打开应用后，日志查看器会自动加载最新的日志文件
2. 通过下拉菜单切换不同的日志文件
3. 使用工具栏按钮控制显示选项

### 筛选日志

1. 勾选 "筛选面板" 显示筛选选项
2. 取消勾选不需要的日志级别
3. 点击 "应用筛选" 查看结果

### 搜索日志

1. 在搜索框输入关键词
2. 勾选 "正则" 使用正则表达式
3. 点击 "搜索" 执行搜索
4. 点击 "清除" 清空搜索条件

### 去重

1. 在筛选面板勾选 "启用去重"
2. 选择 "仅连续" 只合并连续重复项
3. 重复次数会显示在消息后面（如 x3）

## 配置

插件会自动扫描以下目录寻找日志文件：

- `logs/`
- `build/bin/logs/`
- `../logs/`
- `../build/bin/logs/`
