## 1. 概述

### 1.1 规范目的

本规范旨在统一DearTs项目的代码风格，提高代码质量、可读性和可维护性，确保团队成员之间的高效协作。

### 1.2 基本原则

- **一致性**：所有代码遵循统一的风格和约定
- **可读性优先**：代码首先应该易于理解
- **现代化**：优先使用C++20特性和现代C++最佳实践
- **性能导向**：在保证可读性的前提下，追求高性能
- **安全可靠**：强调内存安全和错误处理

### 1.3 适用范围

本规范适用于DearTs项目的所有C++源代码文件，包括但不限于：
- 核心框架代码 (`core/`)
- 演示程序 (`demo/`)
- 主应用程序 (`main/`)
- 库组件 (`lib/`)

## 2. 命名规范

### 2.1 通用规则

- **英文名称**：所有标识符使用英文单词，避免使用拼音
- **语义明确**：名称应该能清楚表达其用途和含义
- **避免缩写**：除非是广泛认知的缩写（如`max`、`min`等）
- **长度适中**：名称既要表达清楚，又不应过长

### 2.2 类命名

**规则**：使用PascalCase（大驼峰命名）

```cpp
// ✅ 正确
class Application;
class ImGuiLayer;
class InputManager;
class CustomTitleBar;

// ❌ 错误
class application;
class imgui_layer;
class INPUT_MANAGER;
```

**特殊情况**：
- 接口类以`I`开头：`IApplicationLayer`、`IInputHandler`
- 抽象基类可以添加`Base`后缀：`LayerBase`、`WindowBase`
- 异常类以`Exception`结尾：`SDLException`

### 2.3 函数命名

**规则**：使用snake_case（下划线连接），以区分类名（PascalCase）和函数名

```cpp
// ✅ 正确
void on_init();
void handle_event(const SDL_Event& event);
bool add_layer(std::shared_ptr<IApplicationLayer> layer);
std::string get_window_title() const;

// ❌ 错误
void OnInit();      // 与类名混淆
void HandleEvent(); // 大驼峰应该用于类名
bool AddLayer();    // 与类名格式相同
```

**特殊情况**：
- 访问器函数：`get_xxx()`、`set_xxx()`
- 布尔返回值：`is_xxx()`、`has_xxx()`、`can_xxx()`
- 事件处理函数：`on_xxx()`、`handle_xxx()`
- 回调函数：`callback_xxx()`

### 2.4 变量命名

**成员变量**：snake_case + `m_`前缀

```cpp
// ✅ 正确
class Application {
private:
    std::unique_ptr<AppState> m_app_state;
    std::vector<std::shared_ptr<IApplicationLayer>> m_layers;
    bool m_is_running;
    SDL_Window* m_window;
};

// ❌ 错误
class Application {
private:
    std::unique_ptr<AppState> app_state;      // 缺少m_前缀
    std::vector<std::shared_ptr<IApplicationLayer>> layers;  // 大写开头
    bool m_is_running;                         // 驼峰命名不规范
};
```

**局部变量**：snake_case

```cpp
// ✅ 正确
void ProcessInput() {
    int keyCode = event.key.keysym.sym;
    std::string inputText = GetInputText();
    float deltaTime = CalculateDeltaTime();
}

// ❌ 错误
void ProcessInput() {
    int Key_Code = event.key.keysym.sym;     // 下划线命名
    std::string InputText = GetInputText();  // 大写开头
};
```

**常量和静态变量**：UPPER_CASE + 下划线

```cpp
// ✅ 正确
class Constants {
public:
    static const int WINDOW_WIDTH = 1920;
    static const int WINDOW_HEIGHT = 1080;
    static const std::string APP_NAME;
};

// ❌ 错误
class Constants {
public:
    static const int windowWidth = 1920;    // 小写
    static const int Window_Height = 1080;  // 混合命名
};
```

### 2.5 文件命名

**规则**：snake_case（下划线分隔）

```cpp
// ✅ 正确
application.h
application.cpp
imgui_layer.h
imgui_layer.cpp
input_manager.h
input_manager.cpp

// ❌ 错误
application.h          // 大写开头
application_layer.h    // 驼峰命名
input_manager.cpp     // 连字符
```

### 2.6 命名空间命名

**规则**：PascalCase，避免过长的命名空间

```cpp
// ✅ 正确
namespace DearTs {
    namespace UI {
        class ImGuiLayer;
    }
    namespace Input {
        class InputManager;
    }
}

// ❌ 错误
namespace dear_ts_gui_framework {  // 过长且包含下划线
namespace gui_framework_ui {       // 缩写不明确
```

## 3. 代码格式化

### 3.1 基本规则

**缩进**：4个空格，不使用制表符

```cpp
// ✅ 正确
if (condition) {
    if (nestedCondition) {
        DoSomething();
    }
}

// ❌ 错误
if (condition) {
  if (nestedCondition) {    // 2空格缩进
      DoSomething();        // 混合空格和制表符
  }
}
```

**括号风格**：K&R风格（左括号不换行）

```cpp
// ✅ 正确
if (condition) {
    DoSomething();
} else {
    DoSomethingElse();
}

for (int i = 0; i < count; i++) {
    ProcessItem(items[i]);
}

// ❌ 错误
if (condition)
{
    DoSomething();
}

for (int i = 0; i < count; i++)
{
    ProcessItem(items[i]);
}
```

### 3.2 空格使用

**操作符周围**：必须有空格

```cpp
// ✅ 正确
int x = a + b * c;
bool result = (condition1 && condition2) || condition3;

// ❌ 错误
int x = a+b*c;              // 操作符无空格
bool result = (condition1&&condition2)||condition3;
```

**逗号后**：必须有空格

```cpp
// ✅ 正确
void Function(int param1, float param2, const std::string& param3);

// ❌ 错误
void Function(int param1,float param2,const std::string& param3);
```

**括号内**：无空格

```cpp
// ✅ 正确
if (condition) {
    DoSomething();
}

// ❌ 错误
if ( condition ) {         // 括号内有空格
    DoSomething( );
}
```

**函数调用**：函数名与括号间无空格

```cpp
// ✅ 正确
DoSomething();
ProcessData(data, count);

// ❌ 错误
DoSomething ();
ProcessData (data, count);
```

### 3.3 行长度和对齐

**行长度限制**：建议120字符，最长不超过150字符

```cpp
// ✅ 正确 - 适当换行
void LongFunctionName(
    const std::string& parameter1,
    int parameter2,
    const std::vector<std::shared_ptr<SomeClass>>& items
) {
    // 函数体
}

// ✅ 正确 - 对齐
auto result = someVeryLongVariableName + anotherLongName +
              yetAnotherLongVariable + shortVar;

// ❌ 错误 - 行过长
void LongFunctionName(const std::string& parameter1, int parameter2, const std::vector<std::shared_ptr<SomeClass>>& items) {
    // 函数体
}
```

**模板参数对齐**：

```cpp
// ✅ 正确
template<
    typename T,
    typename U,
    typename V = std::default_allocator<T>
>
class Container {
    // 类定义
};

// ❌ 错误
template<typename T, typename U, typename V = std::default_allocator<T>>
class Container {
    // 类定义
}
```

### 3.4 语句格式化

**条件语句**：

```cpp
// ✅ 正确
if (condition) {
    DoSomething();
} else if (anotherCondition) {
    DoSomethingElse();
} else {
    DoDefault();
}

// ✅ 正确 - 复杂条件换行
if (longCondition1 && 
    longCondition2 || 
    longCondition3) {
    DoSomething();
}

// ❌ 错误
if ( condition )
{
    DoSomething ( );
}
```

**循环语句**：

```cpp
// ✅ 正确
for (int i = 0; i < count; i++) {
    ProcessItem(items[i]);
}

// ✅ 正确 - 范围for循环
for (const auto& item : items) {
    ProcessItem(item);
}

// ✅ 正确 - while循环
while (condition) {
    DoSomething();
}

// ✅ 正确 - do-while循环
do {
    DoSomething();
} while (condition);
```

**switch语句**：

```cpp
// ✅ 正确
switch (value) {
    case CASE1:
        DoSomething();
        break;
    
    case CASE2:
        DoSomethingElse();
        // 故意fall-through
    case CASE3:
        DoCommon();
        break;
    
    default:
        DoDefault();
        break;
}

// ❌ 错误
switch(value){
    case CASE1:
    DoSomething();break;
    case CASE2:
        DoSomethingElse();break;
}
```

## 4. 注释规范

### 4.1 注释原则

- **解释"为什么"**：注释应该解释代码的意图和设计决策，而不是简单描述代码行为
- **保持同步**：代码修改时必须同步更新相关注释
- **避免过多**：好的代码本身就是最好的文档，避免不必要的注释
- **使用标准格式**：统一使用Doxygen格式

### 4.2 文件头注释

每个源文件必须包含文件头注释：

```cpp
/**

 * @date 2025-11
 * @version 1.0
 * 
 * Copyright (c) 2024 DearTs Project. All rights reserved.
 */

#pragma once

#include "SDL3/SDL.h"
#include "imgui.h"
// ... 其他包含
```


## 5. C++现代特性使用

### 5.1 智能指针

**优先使用智能指针**，避免原始指针和手动内存管理：

```cpp
// ✅ 正确 - 使用智能指针
class Application {
private:
    std::unique_ptr<AppState> m_appState;                    // 独占所有权
    std::vector<std::shared_ptr<IApplicationLayer>> m_layers; // 共享所有权
    std::weak_ptr<ResourceManager> m_resourceManager;        // 弱引用
};

// ✅ 正确 - 工厂函数返回智能指针
std::unique_ptr<Window> CreateWindow(const WindowConfig& config) {
    return std::make_unique<Window>(config);
}

// ❌ 错误 - 使用原始指针管理资源
class Application {
private:
    AppState* m_appState;           // 需要手动delete
    IApplicationLayer** m_layers;   // 需要手动delete[]
};
```

**智能指针选择原则**：
- `std::unique_ptr`：单一所有权，首选
- `std::shared_ptr`：多个所有者共享所有权
- `std::weak_ptr`：观察`std::shared_ptr`，避免循环引用

### 5.2 RAII模式

**资源获取即初始化**，确保资源自动管理：

```cpp
// ✅ 正确 - RAII模式
class TextureLoader {
public:
    TextureLoader(const std::string& path) {
        m_texture = IMG_LoadTexture(path.c_str());
        if (!m_texture) {
            throw std::runtime_error("Failed to load texture: " + path);
        }
    }
    
    ~TextureLoader() {
        if (m_texture) {
            SDL_DestroyTexture(m_texture);
        }
    }
    
    // 禁用拷贝，允许移动
    TextureLoader(const TextureLoader&) = delete;
    TextureLoader& operator=(const TextureLoader&) = delete;
    TextureLoader(TextureLoader&& other) noexcept : m_texture(other.m_texture) {
        other.m_texture = nullptr;
    }

private:
    SDL_Texture* m_texture = nullptr;
};

// ❌ 错误 - 手动资源管理
void LoadTexture() {
    SDL_Texture* texture = IMG_LoadTexture("image.png");
    // 使用texture...
    
    // 如果在中间抛出异常，这里不会执行，导致内存泄漏
    SDL_DestroyTexture(texture);
}
```

### 5.3 Lambda表达式

**使用Lambda表达式简化代码**：

```cpp
// ✅ 正确 - 使用Lambda进行事件处理
auto eventCallback = [this](const SDL_Event& event) -> bool {
    if (event.type == SDL_EVENT_QUIT) {
        RequestQuit();
        return true;
    }
    return false;
};

// ✅ 正确 - 使用Lambda进行算法操作
std::vector<int> activeLayers;
std::copy_if(m_layers.begin(), m_layers.end(), 
             std::back_inserter(activeLayers),
             [](const auto& layer) { return layer && layer->IsActive(); });

// ✅ 正确 - 捕获this进行成员访问
void Button::OnClick() {
    auto callback = [this]() {
        if (m_callback) {
            m_callback();
        }
        UpdateState();
    };
    ExecuteOnClick(callback);
}

// ✅ 正确 - 移动捕获避免拷贝
auto ProcessLargeData(std::vector<std::string> data) {
    auto processor = [data = std::move(data)]() mutable {
        for (auto& item : data) {
            ProcessItem(item);
        }
    };
    return processor;
}
```

### 5.4 自动类型推导

**适度使用`auto`**，提高代码可读性：

```cpp
// ✅ 正确 - 复杂类型使用auto
auto it = std::find_if(m_layers.begin(), m_layers.end(),
                      [&layer](const auto& ptr) { return ptr.get() == layer; });

auto config = std::make_unique<WindowConfig>();
auto callback = std::bind(&Application::HandleEvent, this, std::placeholders::_1);

// ✅ 正确 - 范围for循环
for (const auto& layer : m_layers) {
    layer->OnEvent(event);
}

// ✅ 正确 - 返回值推导
auto CreateWindow() -> std::unique_ptr<Window>;

// ❌ 错误 - 过度使用auto
auto x = 5;           // int更明确
auto flag = true;     // bool更明确
auto name = "Hello";  // const char*更明确

// ❌ 错误 - 影响代码理解
auto result = SomeComplexFunction();  // 返回类型不明确，难以理解
```

### 5.5 范围for循环

**优先使用范围for循环**：

```cpp
// ✅ 正确 - 范围for循环
for (const auto& layer : m_layers) {
    layer->OnUpdate(deltaTime);
}

for (auto& [key, value] : m_keyBindings) {
    if (IsKeyPressed(key)) {
        value();
    }
}

// ✅ 正确 - 需要索引时使用传统循环
for (size_t i = 0; i < m_layers.size(); ++i) {
    const auto& layer = m_layers[i];
    layer->SetIndex(static_cast<int>(i));
}

// ❌ 错误 - 使用传统循环迭代器
for (auto it = m_layers.begin(); it != m_layers.end(); ++it) {
    (*it)->OnUpdate(deltaTime);
}
```

### 5.6 结构化绑定

**使用结构化绑定简化代码**：

```cpp
// ✅ 正确 - 解构键值对
std::map<std::string, int> scores;
for (const auto& [name, score] : scores) {
    std::cout << name << ": " << score << std::endl;
}

// ✅ 正确 - 解构元组
auto [success, data, error] = ParseJson(jsonString);
if (success) {
    ProcessData(data);
} else {
    LogError(error);
```

```cpp
// ✅ 正确 - 任务系统用于并行处理
class TaskSystem {
public:
    using Task = std::function<void()>;
    
    TaskSystem(size_t numThreads = std::thread::hardware_concurrency()) {
        for (size_t i = 0; i < numThreads; ++i) {
            m_workers.emplace_back([this] { WorkerLoop(); });
        }
    }
    
    ~TaskSystem() {
        {
            std::lock_guard<std::mutex> lock(m_queueMutex);
            m_shouldStop = true;
        }
        m_condition.notify_all();
        
        for (auto& worker : m_workers) {
            worker.join();
        }
    }
    
    void SubmitTask(Task task) {
        {
            std::lock_guard<std::mutex> lock(m_queueMutex);
            m_tasks.emplace(std::move(task));
        }
        m_condition.notify_one();
    }
    
    template<typename Iterator, typename Function>
    void ParallelFor(Iterator first, Iterator last, Function func) {
        const size_t count = std::distance(first, last);
        const size_t numThreads = std::min(m_workers.size(), count);
        
        if (numThreads <= 1 || count < 1000) {  // 小任务直接执行
            std::for_each(first, last, func);
            return;
        }
        
        std::atomic<size_t> nextIndex{0};
        std::vector<std::future<void>> futures;
        
        for (size_t i = 0; i < numThreads; ++i) {
            futures.emplace_back(std::async(std::launch::async, [&]() {
                while (true) {
                    size_t index = nextIndex.fetch_add(1);
                    if (index >= count) break;
                    
                    auto it = std::next(first, index);
                    func(*it);
                }
            }));
        }
        
        // 等待所有任务完成
        for (auto& future : futures) {
            future.wait();
        }
    }

private:
    std::vector<std::thread> m_workers;
    std::queue<Task> m_tasks;
    std::mutex m_queueMutex;
    std::condition_variable m_condition;
    bool m_shouldStop = false;
    
    void WorkerLoop() {
        while (true) {
            Task task;
            {
                std::unique_lock<std::mutex> lock(m_queueMutex);
                m_condition.wait(lock, [this] { return !m_tasks.empty() || m_shouldStop; });
                
                if (m_shouldStop && m_tasks.empty()) {
                    return;
                }
                
                task = std::move(m_tasks.front());
                m_tasks.pop();
            }
            
            task();
        }
    }
};
```
